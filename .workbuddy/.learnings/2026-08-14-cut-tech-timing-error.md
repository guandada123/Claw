# 复盘：「砍科技」择时错误（板块强弱定义陷阱）

> 日期：2026-08-14 ｜ 类型：择时/风控根因 ｜ 标记：★升级候选（建议升为铁律）

## 现象
2026-08 初系统在「大级别板块启动前（08-03 绝对底部）」系统性砍/弃科技与半导体：
- 实盘封测链（长电/华天）连续触发 -8% 止损卖出建议（08-02~08-05，建议在 08-03 绝对底部附近生成）
- 选股层「半导体链证伪放弃」(08-04) / 「科技板块全弃」(08-07)
- 08-04 起科技/半导体大级别主升（长电自底 +27%）

## 根因（代码锚定）
1. **【主因】板块强度用单日涨跌幅定义** `market_sentiment.py:391`：`强 if 当日≥1% else 中 if ≥0 else 弱`。
   动量-only 在筑底区把最强 upcoming 板块判为最弱 → `advisor_rules.check_entry` 弱市+弱板块 block 推荐。
2. **缺「底部反转/早期转折」维度**：系统只有追强/避弱两态，无"弱势板块正在筑底反转"识别。
3. **-8% 静态止损无板块级状态感知**：实盘 100% 封测链相关性事件，correlation_monitor 只读模拟盘（未接实盘）。
4. **A2 拥挤度预警语义越界**：板块主题级阻断 re-entry（应为个股级）。
5. **砍仓后无回溯/再进入机制**。

## 修复（已落地 2026-08-14，F1-F6 全闭环）
- **F2（选股入场闸）**：新增 `scripts/sector_strength_layer.py`（QTS PG 多周期动量 5/10/20d+MA20+跨板块RPS），输出 Top3 强 + 早期转折 + scan_focus_codes。`advisor_rules.check_entry` 接入层：弱市+弱板块 block，但 `layer_early` 降级为 warn 不 block（验证通过）。
- **F3（实盘接 correlation_monitor）**：`correlation_monitor.py` 新增 `--source sim|user|both`（默认 sim 向后兼容）。实盘源 min_holdings 降至 2（同源双标如封测链长电+华天通常仅2只），触发时提示「减仓最相关一只、保留单因子暴露、勿双杀」。实测 600584+002185 相关 0.92 → WARN。
- **F4（止损板块级低位例外）**：`advisor_rules.check_timing` A3 紧急减仓分支：若标的板块处「早期转折」(layer early) → 降级为 warn「持有观察/低位不裸卖」，不裸卖在周期性底部。实测 华天(-17.88%)+半导体早期转折 → 由 block 降级 warn；真弱势/层不可用仍 block（安全不误放行）。
- **F6（砍仓后回溯再进入 gate）**：新增 `check_reentry_signal()` + `diagnose_holding` 集成：近期(≤30d)有卖出且板块转强(Top3)/早期转折 → 输出「再进入评估」提示，避免砍在底部后彻底错过启动。新增 diagnose CLI `--trade-log` 供喂交易历史。
- `STRATEGY.md` 加「板块强弱层」节 + 下方 F3/F4/F6 补遗。

## 铁律候选（防再犯）
- 🔴 板块强弱禁止用单日涨跌幅单独判定；必须用多周期动量 + 早期转折识别。
- 🔴 早期转折板块（筑底反转/刚启动）= 布局窗口，不得按「弱板块」暂缓推荐（即"砍在启动前"根因）。
- 🔴 **静态止损须感知板块级 early 信号（F4）**：持仓破 -8% 但所属板块处早期转折（动量拐头/站上MA20）→ 降级为「持有观察/低位不裸卖」，不得裸卖在周期性底部；仅个股利空(非板块同步下挫)才裸卖。
- 🔴 静态止损须感知板块级/相关性事件，封测链类高相关持仓遇板块洗盘不得双杀清仓（F3）。
- 🔴 砍仓后须回溯：板块转强(早期转折/Top3)即触发再进入评估，不得一刀切断（F6）。

## 经验
- 回放验证法：用 PG 真实价格轨迹（底部+启动）回放，能一眼定位"砍在启动前"的机制性盲区，比纯叙事有力。
- Claw 本地工作区按平台限制不托管新定时自动化 → 每日数据任务改为由既有 Claw 托管自动化（选股）前置调用，而非新建 automation。
