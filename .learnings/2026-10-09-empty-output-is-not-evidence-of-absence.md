# ★升级候选：`ls` / `Glob` / `find` 的「无输出」不是「不存在」的证据

**日期**：2026-10-09（编制《本机记忆系统说明文档》时首次踩到）
**等级**：P1（差点把「本机最大的记忆资产」判成「不存在」，并在正式文档里写下相反结论）
**类型**：correction（诊断口径错误）
**状态**：已定性 + 已修正文档；规则候选

---

## 1. 现象

编制记忆系统文档时，需要确认「对话正文是否存在本机」。三种工具依次给出「不存在」：

| 动作 | 输出 | 真实情况 |
|---|---|---|
| `Glob /Users/guan/.workbuddy/projects/*` | `No files found` | 该目录有 **255 个子目录** |
| `ls /Users/guan/.workbuddy/projects \| head` | **Permission denied**（Bash 工具层直接拒绝，非 OS 报错） | 可读 |
| `find ~/.workbuddy -name '*.jsonl' -size +100k` | **0 命中** | 该目录有 **3,844 MB / 10,470 个 .jsonl** |
| `du -sh ~/.workbuddy` | `0B` | 实际 18 GB |

依据这三个「证据」，v1 文档写下了头号结论：**「对话正文不在本机，只留元数据」**。
直到用 `python3 -c "os.listdir(...)"` 交叉验证，才发现完全相反。

## 2. 根因（三条独立叠加，且都静默）

1. **`Glob` 对该路径返回空**：工具层对 `/Users/guan/.workbuddy/projects` 下的匹配结果为空 —— 无任何错误提示。
2. **`ls` 被权限层前置拦截**：Bash 工具直接返回 `permission denied`，看起来像"OS 不允许读"，**实际是工具沙箱策略**，与文件系统权限无关（同目录 `python os.listdir` 畅通无阻）。命令被判 denied 后，很容易被当成"路径有问题"而不深究。
3. **`find` 静默 0 命中**：没有报错、没有警告，退出码也未必非 0 —— 与「确实没有」的输出**完全无法区分**。

4. **`du -sh <软链>` 返回 0B**：`/Users/guan/.workbuddy` 本身是**软链**（→ `/Volumes/ZHITAI/workbuddy_data`），`du` 默认不跟随软链 → 报 `0B`。这被误读为"空目录"，实际 18 GB。**同一根因还害了另一处**：`ls -ld` 对软链目录显示的是 `drwxr-xr-x`（加了 `-d` 不显示箭头时要看**首字符 `l`**），导致「`/Users/guan/WorkBuddy` 是真实目录」的错误判断。

- v1.1 新增 §2.2「★对话正文归档」章，把该目录升级为「最应被保护、也最易被误删」的资产。

## 4. 防复犯（规则候选）

> **「查无此物」之前，必须先反证「工具本身能看见这个目录」。**

三条硬性动作：
1. **交叉验证**：任何"不存在/为空"的结论，必须用**第二种机制**复核。首选 `python3 -c "import os; print(len(os.listdir(P)))"` —— 它绕过工具层 glob 与 shell 权限策略，直连 POSIX。
2. **区分「拒绝」与「不存在」**：`Permission denied` 是**工具策略**，不等于路径有问题；见到它就换机制，而不是换路径。
3. **软链要先看首字符**：路径判断一律先 `ls -ld` 看**首字符是否为 `l`**，或直接 `python3 -c "from pathlib import Path; p=Path(P); print(p.is_symlink(), p.resolve())"`。凡解释器/脚本内做路径推导，**不得用 `du` 的输出判断体积**，也不得用裸 `ls -ld` 的 `drwx` 前缀判断"非软链"。

## 5. 去重

- 与已有铁律「🔴 `grep -c` 返回 0 时先验证模式本身能命中，再信『查无此物』」**同族**（都是"零结果 ≠ 无此物"），但本例暴露三条**新缺口**：
  ① 不止 `grep`，`Glob` / `find` / `ls` 都会静默返空；
  ② `permission denied` 来自**工具策略层**而非 OS，会被误读为路径异常；
  ③ 软链使 `du` 恒返 `0B`、使 `ls -ld` 的 `d` 前缀具误导性。
- 与「🔴 项目路径落外置 SSD/符号链接须防静默失败」同源，但那条讲的是**运行期 IO 失败**，本条的失效点在**勘察/诊断期的存在性判断**。
